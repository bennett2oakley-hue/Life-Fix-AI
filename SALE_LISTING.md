## Product positioning
Life Fix AI addresses a simple consumer problem: people often know something is wrong but do not know what to do first. The product asks the user to describe the problem and returns a practical sequence of next actions instead of a wall of generic information.

The current build is a client-side product. User problem history is stored locally in the browser rather than sent to a central database.

## Current status
**Working MVP / pre-revenue.**

The current problem-solving engine is deterministic rule-based guidance. It does not call a connected generative-AI model or remote AI API. There are no verified revenue, customer, traffic, profit, retention or usage claims attached to this listing.
